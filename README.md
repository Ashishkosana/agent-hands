# agent-hands

Record-once / replay-many computer-use automation. An LLM works out how to
complete a task inside a UI that has no API; the successful run is distilled
into a typed, versioned **capability**; production invocations replay that
capability deterministically — no model in the decision loop.

**Status: under construction.** See [docs/DESIGN.md](docs/DESIGN.md) for the
design. This README will carry setup, the demo path, and eval results once
the core is in place.
