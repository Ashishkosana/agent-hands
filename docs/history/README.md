# Historical documents

Documents written for the August 2026 build and its external technical
review. They are archived unchanged apart from a header note, because they
record what was claimed and known at the time. Nothing here is maintained;
where they disagree with the current code or with the top-level
documentation, the current documentation wins.

| file | what it was | superseded by |
|---|---|---|
| [`REPORT.md`](REPORT.md) | As-built summary of the initial build (architecture, schema, determinism, escalation, safety, cuts). | [`README.md`](../../README.md), [`../DESIGN.md`](../DESIGN.md) |
| [`DESIGN_DOC.md`](DESIGN_DOC.md) | Formal design document mapping the review brief's requirements to the implementation. Section numbers (§2.x, §3.x) refer to that brief. | [`../DESIGN.md`](../DESIGN.md), [`../ADAPTATION.md`](../ADAPTATION.md) |

The state of the repository at the time of that review is tagged
[`buildathon-submission`](https://github.com/Ashishkosana/agent-hands/releases/tag/buildathon-submission).
